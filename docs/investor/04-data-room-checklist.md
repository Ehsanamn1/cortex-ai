# Cortex AI — Investor Data Room Checklist

## 1. Company
- [ ] legal entity / founder ownership documents
- [ ] incorporation records
- [ ] cap table
- [ ] founder agreements
- [ ] IP ownership / invention assignment
- [ ] domain ownership
- [ ] trademarks, if any

## 2. Product
- [ ] production URL
- [ ] product demo account
- [ ] architecture overview
- [ ] release checklist
- [ ] security summary
- [ ] backup / recovery policy
- [ ] incident response policy
- [ ] roadmap

## 3. Traction
- [ ] monthly KPI export
- [ ] activation funnel
- [ ] WAU / MAU
- [ ] paid workspaces
- [ ] MRR / top-up revenue
- [ ] retention cohorts
- [ ] churn
- [ ] customer testimonials / case studies where permitted

## 4. Financials
- [ ] 18-month operating model
- [ ] revenue assumptions
- [ ] AI/model COGS assumptions
- [ ] infrastructure cost assumptions
- [ ] hiring plan
- [ ] monthly cash burn
- [ ] runway
- [ ] use of funds
- [ ] unit economics

## 5. Technical diligence
- [ ] repository
- [ ] CI/CD history
- [ ] production architecture
- [ ] data model
- [ ] secret-management design
- [ ] tenant isolation
- [ ] auth/session design
- [ ] model/provider abstraction
- [ ] backup strategy
- [ ] dependency policy

## 6. Commercial
- [ ] current price catalog
- [ ] sales pipeline
- [ ] customer segments
- [ ] acquisition channels
- [ ] competitive alternatives
- [ ] positioning
- [ ] sales motion
- [ ] expansion strategy

## 7. Fundraising
- [ ] pitch deck
- [ ] one-page investor brief
- [ ] funding target
- [ ] instrument proposed with counsel
- [ ] investor target list
- [ ] outreach tracker
- [ ] meeting notes
- [ ] diligence Q&A

## Red flags to resolve before sharing

- No invented traction.
- No unsupported market-size claims.
- No unverified customer logos.
- No vague "AI platform" language without a concrete workflow.
- No financial projection presented as historical fact.
- No claims that model quality is proprietary when the core models are third-party.
